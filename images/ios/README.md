# iOS store assets

App Store screenshots and previews for the app, split by device.

- **[iphone/](iphone/README.md)**: 10 screenshots plus 3 app previews, captured
  on the iPhone 17 simulator at 1206 by 2622 pixels.
- **[ipad/](ipad/README.md)**: 10 screenshots, captured on the iPad Pro
  13-inch simulator at 2064 by 2752 pixels.

Both sets use the same sample profile ("Ayaan") so the app looks lived in
rather than freshly installed. See each folder's own README for the shot by
shot breakdown and notes for the listing.
