# Store screenshots & previews (iOS)

Publication-ready App Store assets captured from the app running on the
**iPhone 17 simulator** (iOS 26), using a realistic sample profile ("Ayaan"):
~50 days of daily growth-hormone injections rotating across six sites, a dose
titration (0.4 → 0.6 mg), and six months of growth measurements.

**Screenshots:** PNG, **1206 × 2622** (iPhone 17 native @3x, 6.3" display class).
**App previews:** H.264 .mp4, **1206 × 2622** portrait, 24–28 s each.

## Notes for the listing
- App Store Connect allows up to **10** screenshots and **3** app previews per
  device size — this is the full set.
- These are **light theme**. Consider a couple of dark-theme shots
  (Settings → Appearance → Dark) if you want to show it off.
- Previews were captured as native screen recordings and time-scaled to fit the
  30-second App Store limit (`tool`-side, via AVFoundation). If App Store Connect
  rejects the exact dimensions for a given device tier, re-encode/re-capture to
  the required app-preview resolution.
